AI分野では、AIエージェントが大量のツールを効率よく扱うための仕組みや、ブラウザ内で動く小型AIモデルが登場。IT分野では、Webアプリの脆弱性対策、データ品質監視、Kubernetesのネットワーク機能などに注目。

AIニュース

Google　2026/11/19

Gemini APIに「Tool Retrieval」が登場

AIエージェントが多数のツールを使う際、すべてのツール仕様を毎回読み込むのではなく、必要になったツールの詳細だけを後から取得できる機能。入力トークンや応答の遅延を抑え、大量のツールを扱うエージェントを効率化する。

開発者向け / Gemini API
Microsoft　2026/11/19

Microsoft Edgeに小型AIモデル「Aion Instruct」を導入

Edgeに組み込まれる小型言語モデルがAion Instructに更新された。約23億パラメータで、要約・文章生成・指示への応答などを端末側で処理する。クラウドに毎回問い合わせずに済むため、Webサイト上でのAI機能の実装にもつながる。

ブラウザ / オンデバイスAI
Google　2026/11/19

生成AIモデル「Genie 4」がGemini APIから利用可能に

テキストや参考画像から、操作できる仮想空間を生成するGenie 4がGemini APIとGoogle AI Studioで利用可能になった。開発者はゲームやシミュレーション、ロボット学習などに向けた実験を進められる。

ITニュース

Cloudflare　2026/11/20

Rubyの脆弱性「ruby2shell」へのWAF対策を公開

Rubyのメモリ破壊につながる脆弱性（CVE-2026-132825）について、CloudflareがWAFで攻撃をブロックする仕組みを説明。RailsやSinatraを利用している場合は、WAFだけに頼らずRubyのバージョン確認とアップデートが重要。

セキュリティ / Ruby
AWS　2026/11/20

AWS Glue Data Catalogでデータ品質をまとめて監視可能に

カタログやデータベース単位で品質チェックを一度設定すれば、対象テーブルをまとめて定期評価できるようになった。後から追加したテーブルも対象にできるため、データ基盤での品質チェック運用を簡素化できる。

クラウド / データ基盤
Google Cloud　2026/11/20

GKEでサイドカー不要の「Ambient Networking」が一般提供

Kubernetesのサービスメッシュ機能を、各アプリケーションPodのサイドカーではなくノード側の共有コンポーネントで提供する方式。Podごとのプロキシ管理やリソース消費を抑え、通信の保護・監視・ルーティングを行いやすくする。

Kubernetes / ネットワーク
Google Workspace　2026/11/20

Google Vaultが外部スペースやグループチャットの保存に対応へ

Google Chatの外部スペースやグループDMについて、参加組織ごとにメッセージを保持・検索・エクスポートできるようになる。企業の監査やコンプライアンス対応を強化する機能で、展開開始は2027年2月中旬の予定。
